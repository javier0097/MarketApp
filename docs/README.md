How to run, publish and install the app is in the [root README](../README.md).
These documents explain the decisions behind the code.

- [Data model](data-model.md): entities, fields and why they are shaped this way.
- [Development](development.md): tooling decisions the config files cannot explain.

## Opening the docs in Obsidian

Open the `docs/` folder as a vault (*Open folder as vault*). Its settings
folder, `docs/.obsidian/`, is git-ignored.

Write links in standard Markdown (`[Data model](data-model.md)`), not as
wikilinks (`[[data-model]]`), so they also work on GitHub. In Obsidian:
*Settings → Files and links* → turn off *Use [[Wikilinks]]*.
